### 🌟 Featured Projects

#### 🧙‍♂️ [Mithrandir](https://github.com/Antux912012/mithrandir)
> **Modern Linux System Cleaner, Optimizer & Kernel Power Utility**
- **Rust + GTK4 / Libadwaita**: High-performance, modern GUI adhering strictly to GNOME HIG standards.
- **Hardware & Kernel Tuning**: Dynamic BORE / EEVDF scheduler switching, BPF `sched-ext` controller, CPU EPP & frequency governor management.
- **AI System Optimization**: Multi-provider LLM integration (OpenAI, Claude, Gemini, Cursor) + local agent bridging (`antigravity`, `openclaude`, `codex`) and local runner integration (LM Studio, Ollama, llama.cpp).
- **Vulkan / OpenGL Acceleration**: Dynamic GSK hardware acceleration with pure Cairo software fallback.
- **Strict Data-Loss Guardrails**: Sandboxed cache cleaner with zero risk to app configurations.
